# Temporary character figures

These original local SVG placeholders are separate 900×1400 transparent standing figures, not scaled portrait cameos. Alice has a plum dress/jacket and pinned-up hair, Ben an olive work coat and beard, Clara a structured blue coat and longer hair. The generic figure supports unknown public identities or missing assets. Their neutral presentation encodes no guilt, ownership, private relationships or inferred emotional state.

Replace figure paths in `src/presentation/asset-manifest.js` without changing room rules or API logic. The `neutral` entry leaves room for future reviewed pose/expression assets, but this milestone never selects inferred expressions or implements emotional AI. Backgrounds and cameo portraits remain separate assets. These figures are temporary illustrations, not final character art.
