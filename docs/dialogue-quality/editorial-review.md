# Testimony equivalence and dialogue review

This is the assistant's editorial review of the authored repertoire, separate from mechanical evaluation and later user playtest judgment. `test/fixtures/reviewed-testimony.json` freezes the exact accepted speech strings independently of runtime catalog lookups. Original case records and annotations are untouched. Exact pair validation prevents unreviewed generated changes; it does not establish that an author wrote equivalent prose.

Review corrections made before acceptance: removed a new claim that the window “needed” repairing; removed storm-caused-mud causation; narrowed a broad doorway denial to the footprints; retained “could be demanding”; replaced “could not see” with “saw no one clearly”; removed an inferred inability to tell Clara's later whereabouts. These corrections reflect factual/epistemic review, not repetition-score tuning.

Social replies request a specific/direct question or reject an insinuation. They reveal no case fact and never replace an authorized substantive answer. Clarification alternatives refer to the current speaker's committed core only. Pressure alternatives use the same assertions, sometimes clipped or reordered, without confessing or weakening denials. Core eligibility and comparison prerequisites are unchanged.

## Narration review

Every narration is a literal visible action of the addressed NPC: hands/clothing, a brief pause/breath, gaze/facial movement or a small posture adjustment. Existing gesture texts plus new restrained expressions/postures contain no detective action, object transfer/destruction, new room movement, hidden mental cause or guilt interpretation. Families describe the visible action, not the suspect's truthfulness. A cursor advances only after an actual selected gesture so later alternatives are reachable; it cannot consume an unseen fallback gesture. Null remains available. Pacing normally allows two speech-only replies between narrations; the first already-authorized comparison may have a single reviewed contextual pause during cooldown. The report records any such exception.

## 3. Subjective personality and naturalness assessment

The assistant assessed the actual evaluated transcripts, with these limits: finite authored selection, no live provider, no user or independent human rating. Direct topic answers now begin with an account or detail. Alice's limited observation and carefully bounded timing remain recognizable; Ben's greenhouse fragments and relevant repeated explanation distinguish him from Clara's controlled business wording. Clara's pressured answers use sentence order, emphatic denial and occasional rhetorical formulation rather than the old clarity announcement. Clarification usually makes the scope of the same account explicit.

The improvement is most evident across unrelated topics: there is no repeated character-wide introductory sentence. It is less complete during prolonged pressure on a single core, where the small equivalent repertoire eventually alternates. Some sentence-order changes are modest, and Ben's longer pressured relationship response remains somewhat written rather than conversational. Alice's debt answer deliberately repeats exactly. Silence increases in the last-pair fake selector, which consistently prefers the offered speech-only counterpart; this is valid, not evidence that a real model will make the same choice. Repetition counts alone must not be described as proof that the cast now feels fully natural.

## Manual play checklist for user review

- [ ] Ask all six topics in several orders; check that names, timing, qualifications and intentional denials are preserved.
- [ ] Repeat and clarify one topic under pressure; judge whether the voice remains recognizable without a new catchphrase.
- [ ] Inspect evidence, revisit its relevant suspect, and compare the established Alice/Clara sightings; check for useful answers rather than generic evasion.
- [ ] Review optional narration and speech-only stretches; judge gesture pacing and whether the first comparison reaction feels appropriate.
- [ ] Read the concise demeanor label and open its keyboard-accessible help. Check that it explains delivery versus truthfulness without a technical sentence in every reply.
- [ ] Review history, drafts, navigation, cancellation and both final outcomes offline on desktop/mobile.
- [ ] Judge the actual before/after transcript examples; report overly polished, wordy or still repetitive lines for a later authored-content revision.

This checklist is supplied for human review. Automated browser walkthroughs and assistant visual inspection are recorded separately; unchecked boxes do not imply human playtesting occurred.
